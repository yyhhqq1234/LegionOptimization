# PHASE-05：跨微架构迁移实验（W9–W11，论文第二创新点）

## 1. 阶段目标

用 A 机（255HX）模型证明到 B 机（14900HX）的泛化：fine-tune ≤200 条 B 机样本达到
从零训 3000 条 ≥90% 性能，输出**迁移效率曲线**（论文核心图）。所用 B 机样本计入 P1-3 抽样比。

## 2. 前置依赖

- PHASE-04（A 机预测器 + D_safe_A）；PHASE-01（B 机 UV 锁结论：锁则 B 机 mask 电压维）
- B 机可用连续 3–5 天（含一轮影子采集）

## 3. 详细步骤

### Step 5-1：零样本基线（2 天）
1. A 机 Ensemble 直接测 B 机 test 集：记录 RMSE 掉点数与 τ 衰减（诚实记录，作为图起点）。
2. 域差异归因：硬件指纹 8 维（§State 40–47）中哪几维贡献最大（LightGBM 重要性 + 消融）。

### Step 5-2：三组迁移对比（1 周）
1. Fine-tune：冻前两层，只调最后层 + 200 条 B 机数据。
2. MMD 对齐：特征层加 MMD 损失对齐双机分布，同 200 条预算。
3. Reptile 元学习（可选加分）：每机一 task，小步元更新。
4. 对照组：B 机从零训 3000 条（若时间不够，用学习曲线外推 + 显式声明）。

### Step 5-3：迁移效率曲线（2 天）
横轴 = B 机样本数（0/50/100/200/500），纵轴 = 相对性能（以对照组为 100%），
三条线（fine-tune/MMD/Reptile）+ 零样本起点。200 点达 90% 即达标。

### Step 5-4：B 机预测器冻结
最优路线产出 B 机 ONNX（版本号独立），双机预测器矩阵写入论文表 4-x。

## 4. 阶段验收方法

- [ ] 零样本掉点如实记录（不美化），归因表齐
- [ ] 200 条 fine-tune ≥90% 对照性能（power RMSE 与 τ 双指标）
- [ ] 迁移效率曲线图定稿（可直接进论文）
- [ ] B 机抽样比符合 P1-3（M1/M3/M5/M7 必复、其余≥50%执行记录）
- [ ] 验收：打 `tag phase-05-done`

## 6. 风险与回退

- B 机 UV 锁导致电压维不可迁：mask 后只迁 PL/频墙子空间，结论照写（负结果也是结果）。
