# PHASE-06：B 方案——离线 RL 对比 + OPE + 影子评估（W11–W14，拔高章）

## 1. 阶段目标

以冻结的 `D_safe` 为 Replay Buffer，离线训练策略（BC / TD3+BC / CQL / **IQL 主模型** / Decision Transformer 对比），
经 OPE（FQE + IS）筛选后蒸馏小策略网络（<20MB，CPU <10ms），**纯影子**通过 t4 §5.2 五项门禁。
对应 V16–V21 影子部分；M5 负载预测（TCN）同步交付。

## 2. 前置依赖

- PHASE-04（D_safe 只读快照）、PHASE-05（迁移结论决定 B 机策略是否独立训）
- 全程影子：`--dry-run` 强制开启，任何真实下发即违规停线

## 3. 详细步骤

### Step 6-1：MDP 落定与数据封装（3 天）
1. State48→归一化输入，Action7 连续（B 机按掩码降维），Reward 用 v1.0 权重（含 `−w_burst·B_viol` 与 fluency `φ=3.0`，L0 取 5.0）。
2. 回报缩放 `r/100`，γ=0.99；D_safe 按 W×AC/DC 分层抽样权重，交互探针样本上采样。
3. 划分：训练/验证/留一时间窗 test，跨机 test 复用 P5 划分。

### Step 6-2：五算法对比训练（1.5 周）
| 算法 | 角色 | 关键超参初值 |
|------|------|-------------|
| BC | 下限 baseline | — |
| TD3+BC | 简单强 baseline | α=2.5 |
| CQL | 保守 Q 对比 | α=5.0 |
| **IQL** | **主模型** | expectile τ=0.7，temperature β=3.0 |
| DT | 时髦消融 | context K=20 |

Actor/Critic 各 2×256 MLP；全本地训练（torch cu128），随机种子×3 取均值±std。

### Step 6-3：OPE 离线筛选（3 天）
FQE + 重要性采样双评估，与 BC 基线比较；未显著超越 BC 的策略不得进影子。
输出离线对比表（论文表 5-x）。

### Step 6-4：蒸馏与 M5 预测器（1 周）
1. 最优策略蒸馏为小网络（<20MB），ONNX 导出，CPU 推理延迟实测 <10ms。
2. M5：TCN（备选 2 层 Transformer），过去 60s util → 未来 10s 负载分档；
   交叉熵训练，ONNX ~2MB；与策略叠加规则冻结（M5 定“何时切”，策略定“切多少”）。

### Step 6-5：影子评估 V16–V21（1 周）
84h 有效覆盖（游戏≥2h/办公≥2h/idle≥1h/≥1 次插拔电为一轮，跑满门禁）+ 金丝雀前复核：
1. 动作一致率≥85%；2. 试算 L1+ ≤在运+2pp 且 L2+ =0；3. 流畅 ±5%；
4. 推理零超时（50ms 预算）；5. 日志完整率 100%。

## 4. 阶段验收方法

- [ ] 五算法离线表齐，IQL（或如实记录的更优者）显著超 BC（均值+std，不 cherry-pick 种子）
- [ ] OPE 双评估通过记录；蒸馏后性能保持率≥95% 且延迟达标
- [ ] 影子五项门禁全绿（报告 + 原始 log 可重放）
- [ ] M5 准确率/提前量达标（分档 F1 与 2s 提前触发率，双阈值）
- [ ] 验收：打 `tag phase-06-done`；策略 ONNX 标记 `shadow-only`，解锁 E5 金丝雀申请资格

## 6. 风险与回退

- 离线 RL 全员不超 BC：如实写负结果，主线回退 A+BO（毕业不受影响），B 章改为失败分析（导师通常接受诚实消融）。
- 影子门禁挂项：定位到阈值/数据/模型三类之一修一轮，最多两轮，不过则冻结放量只交影子结论。
- 全程无真实下发；回滚 = 版本回退。
